#### O projekcie
Polish4Sodium to nieoficjalne tłumaczenie dla moda [Sodium](https://modrinth.com/mod/sodium). Jeśli nie wiesz, [Translations for Sodium](https://modrinth.com/resourcepack/translations-for-sodium) ma dużo problemów z tekstem wychodzącym poza ekran, słabym tłumaczeniem, lub poprostu z zostawianiem kawałków tekstu nie przetłumaczone. Ten resourcepack powstał abyś wreszcie mógł spać spokojnie bez głowieniem się co może oznaczać jakieś ustawienie w Sodium.

#### Pobieranie

1. Pobierz najnowsze .zip z GitHub releases, [CurseForge](https://www.curseforge.com/minecraft/texture-packs/polish4sodium) (może być nieaktualna tu) lub [Modrinth](https://modrinth.com/resourcepack/polish4sodium)
2. Przenieś pobraną paczke do folderu "/resourcepacks" twojej gry
3. Aktywuj paczkę w ustawieniach Minecraft
