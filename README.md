## FAQ
### Can i use it in my modpack?
Yes, of course. You do not need permission to do that.
### Something isn't translated
Report it on GitHub (for now not pinned)
### Can it work with every version of Minecraft/[Sodium](https://modrinth.com/mod/sodium)?
Very possible, but not a 100% chance
### Will there be other languages?
No - reason is simple: "Polish"4Sodium, not Translations4Sodium
### Resourcepack has a red background in menu!
Chill, its normal, it was originally created for 1.21.1 but works on every version _(if you use universal release)_ of Sodium/Embeddium/Minecraft
### What about other mods...?
In the future.
### Old versions of Embeddium/Sodium works in half
This is normal because older versions of these mods had a lot of hardcore stuff
