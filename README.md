#### About project
Polish4Sodium an unofficial translation for [Sodium](https://modrinth.com/mod/sodium). If you don't know, [Translations for Sodium](https://modrinth.com/resourcepack/translations-for-sodium) has a lot of problems with text going off-screen, poor translation, or simply not translating something you might care about. This resourcepack was created so you can finally sleep soundly and enjoy playing Minecraft without straining and translating something in Sodium.

#### Download

1. Download latest .zip from GitHub releases, [CurseForge](https://www.curseforge.com/minecraft/texture-packs/polish4sodium) (may be outdated here) or [Modrinth](https://modrinth.com/resourcepack/polish4sodium)
2. Move downloaded file to Minecraft "/resourcepacks" folder
3. Activate the resourcepack in the game
